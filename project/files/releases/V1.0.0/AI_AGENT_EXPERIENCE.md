# AI Agent体验 · V1.0.0

日期：2026-11-17。核心是用户交办业务后，看到澄清、工具执行、工厂协作和可核对的结果。

| 用户交办 | Agent行为 | 演示结果 |
| --- | --- | --- |
| 汇总三厂10月月报 | Main分派三个独立工厂任务，读取已确认来源并汇总 | 初次72台与三厂缺项；补报后108台 |
| 三厂资料补齐了 | 只重试未完成工厂，保留成功结果 | 工艺72台、V2停机18台 |
| 查一下12厂 | 先澄清第12厂还是全部12厂 | 不任取范围 |
| 查看二厂未完成计划 | 调用计划查询工具，交付可打开的记录 | 零星维修、大修、巡检结果 |
| 将某计划改为进行中 | 生成包含旧值、新值的确认卡 | 点击确认后才保存，保存后回读 |
| 分析二厂空调同期用电 | 调用数据与报表能力，固定口径计算 | 100到120 kWh、+20%，标明模拟来源 |
| 检查某上传批次 | 读取映射、错误与来源 | 展示待补信息，人员决定是否提交 |

模型只调用注册工具；范围、写权限、版本与事实来源由服务端校验。AI调用失败会明确显示，不能用固定回复代替真实办理成功。
