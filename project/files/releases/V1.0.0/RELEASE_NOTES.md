# WMS Agent 1.0

软件版本：V1.0.0。Git标签：v1.0.0。日期：2026-11-17。需求基线：PRD V4.1。

## 首次公开发布

为机动能源部门提供可以实际演示的资产与检维修AI协作系统。总部通过Main Agent交办月报，各厂Agent读取已确认数据并统一汇总；业务助手通过自然语言查询和提出变更，人员确认后保存。

## 主要功能

1. **三厂Agent月报**：真实DeepSeek工具调用、独立工厂任务、执行轨迹、来源与模板锁定；缺厂明确标注，补报后只重试未完成工厂。
2. **对话业务助手**：范围澄清、资产和计划查询、计划创建/更新确认卡、保存回读；无任意SQL或生成代码执行。
3. **资产与上报**：12厂432台合成资产；全部资产和工艺设备并排查看；14标准字段、CSV/XLSX预检、A/B/C受控映射、分类维护及月度快照。
4. **检维修与模拟能耗**：零星维修、大修、巡检计划；模拟能耗同期比较及来源标记。
5. **业务可靠性**：后端角色和工厂校验、重复确认幂等、版本冲突、确认过期与撤权、重启持久化、中断状态；月报CSV导出。

## 发布整理

- 界面、API和Java构建号统一到1.0.0；提供VERSION、更新记录、启动手册和本版验证说明。
- 从本地工作区导出独立公开快照，不携带原私有仓库历史、本地密钥、客户原始附件和运行数据。
- 旧演示模块中可能被误认为真实联系方式的样例统一替换为显式占位值；当前AI模块使用合成数据。
- 启动器检查Java/Maven/Node等依赖与端口，前后端均就绪后报告启动完成。
- 沿用开发基线的种子标识和数据结构，已有演示库不会因版本号调整重复初始化。

## 验证

发布前业务基线完成36项自动测试，以及三轮真实DeepSeek联调的55个检查点；浏览器验证月报补报、确认、计划变更、权限与CSV内容。55个是链路检查点，不是55种独立业务或准确率统计。

1.0发布快照的构建与启动复查记录见 [VALIDATION.md](VALIDATION.md)。历史真实API结果与本次重新执行的检查分别标注。

## 已知边界

- Agent月报覆盖一、二、三厂，组织和资产保留全部12厂。
- 能耗为明确标注的模拟数据；审批页面为示意。
- 定时汇报、12厂完整Agent归集、自动恢复续跑、完整双表同步/解锁、任意格式学习和真实计量接入后置。
- 这是可运行Demo，未完成生产部署、客户真实数据验收或全量PRD原子断言验收。
- macOS已实测；Linux/Windows按文档支持标准构建，未在本版进行实机验证。
